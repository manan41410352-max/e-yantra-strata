## Fixes in the verified scripts

- Use TCP orientation feedback to keep the magnetic face level during motion.
- Reject partially hidden colour markers and exclude non-colour depth pixels.
- Retain the last clear camera target through the final descent under wrist occlusion.
- Bound track association distance and distinguish failed pickups from successful releases.
